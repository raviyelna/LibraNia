Create src/hooks/useContent.ts with the following hooks:

**useContent(): { content: Content[]; loading: boolean; error: Error | null; refetch: () => Promise<void> }**
- useState for content array, loading boolean, error
- useEffect on mount: call window.api.content.getAll(), set content state
- useCallback refetch function: re-fetch content from API
- Return content, loading, error, refetch
- Matches useNotes pattern

**useUploadContent(): { upload: (source: 'manual' | 'ai-generated', options?: { confidence_score?: number; note_id?: string; message_id?: string }) => Promise<Content | null>; uploading: boolean; error: Error | null }**
- useState for uploading boolean, error
- useCallback upload function:
  - Set uploading = true
  - Call window.api.content.upload() to show file picker
  - If canceled, return null
  - Call window.api.content.create({ filePath, source, ...options })
  - Return created Content record
  - Catch errors: set error state
  - Finally: set uploading = false
- Return upload function, uploading, error

**useDeleteContent(): { deleteContent: (id: string) => Promise<boolean>; deleting: boolean; error: Error | null }**
- useState for deleting boolean, error
- useCallback deleteContent function:
  - Set deleting = true
  - Call window.api.content.delete(id)
  - Return success boolean
  - Catch errors: set error state
  - Finally: set deleting = false
- Return deleteContent function, deleting, error

**useContentById(id: string | null): { content: Content | null; loading: boolean; error: Error | null }**
- useState for content, loading, error
- useEffect when id changes: call window.api.content.getById(id), set content state
- Return content, loading, error
