  <files>electron/services/graph.service.ts, src/types/graph.ts</files>
  <behavior>
    - getGraphData returns { nodes: GraphNode[], links: GraphLink[] }
    - Nodes include id, title, tags array (from note_tags junction)
    - Links include source, target, type ('manual' | 'semantic'), similarity (for semantic links)
    - Only non-deleted notes included (WHERE deleted_at IS NULL)
    - Links only between non-deleted notes
    - Empty graph returns { nodes: [], links: [] }
  </behavior>
  <action>
Create TypeScript interfaces in src/types/graph.ts:
- GraphNode: { id: string; title: string; tags: string[] }
- GraphLink: { source: string; target: string; type: 'manual' | 'semantic'; similarity?: number }
- GraphData: { nodes: GraphNode[]; links: GraphLink[] }

Create electron/services/graph.service.ts following existing service patterns (notes.service.ts, links.service.ts):
- Import BetterSQLite3Database, schema (notes, links, tags, noteTags)
- Export async function getGraphData(db: BetterSQLite3Database)
- Query notes table: SELECT id, title WHERE deleted_at IS NULL
- For each note, query tags via note_tags junction: JOIN tags ON note_tags.tag_id = tags.id WHERE note_tags.note_id = ?
- Build GraphNode[] with id, title, tags array
- Query links table: SELECT source_note_id, target_note_id, link_type, similarity_score FROM links INNER JOIN notes ON links.source_note_id = notes.id WHERE notes.deleted_at IS NULL
- Build GraphLink[] with source, target, type, similarity (only if semantic link)
- Return { nodes, links }

Follow patterns from RESEARCH.md Graph Service code example. Use Drizzle ORM (eq, isNull) for queries. Handle empty results gracefully.
  </action>

  </verify>
