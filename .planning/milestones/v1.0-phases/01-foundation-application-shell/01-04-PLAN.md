  <name>Task 1: Implement file-based logging system for main and renderer processes</name>
  <files>
    electron/logger.ts
    src/utils/logger.ts
    src/types/logger.ts
    package.json
  </files>
  <behavior>
    - Logger writes to both console and file simultaneously
    - Log file location: userData/logs/app.log
    - Log rotation: new file daily, keep last 7 days
    - Log levels: error, warn, info, debug
    - Log format: [timestamp] [level] [process] message
    - Main process logger writes to main.log
    - Renderer process logger sends logs to main via IPC, then writes to renderer.log
    - Errors include stack traces
  </behavior>
  <action>
    Create logging system implementing D-24 (console + file logging), D-25 (no crash reporting).

    Install dependencies:
    - winston ^3.17.0 (logging library with file transport)
    - winston-daily-rotate-file ^5.0.0 (log rotation)
    - @types/winston (dev dependency)

    Create src/types/logger.ts:
    - Export type LogLevel = 'error' | 'warn' | 'info' | 'debug'
    - Export interface LogEntry { level: LogLevel; message: string; timestamp: string; process: 'main' | 'renderer'; stack?: string }
    - Export interface Logger { error(message: string, error?: Error): void; warn(message: string): void; info(message: string): void; debug(message: string): void }

    Create electron/logger.ts:
    - Import winston, DailyRotateFile from winston-daily-rotate-file
    - Import app from electron
    - Create logs directory: path.join(app.getPath('userData'), 'logs')
    - Configure winston logger with:
      - Console transport: colorize, timestamp, printf format
      - DailyRotateFile transport: filename: 'main-%DATE%.log', datePattern: 'YYYY-MM-DD', maxFiles: '7d', dirname: logs directory
    - Export logger instance with methods: error, warn, info, debug
    - error() method logs message + stack trace if Error object provided
    - Format: `[${timestamp}] [${level}] [main] ${message}`
    - On uncaughtException: log error, show dialog, exit gracefully
    - On unhandledRejection: log error, continue running

    Create src/utils/logger.ts:
    - Import window.electronAPI (from preload)
    - Create logger object with methods: error, warn, info, debug
    - Each method:
      - Logs to console with console[level]
      - Sends log entry to main process via electronAPI.log({ level, message, timestamp, process: 'renderer' })
      - If error object provided, include stack trace
    - Format console output: `[${timestamp}] [${level}] ${message}`
    - Export logger instance

    Update electron/preload.ts:
    - Add to electronAPI namespace:
      - log: (entry: LogEntry) => ipcRenderer.send('log:write', entry)

    Update electron/main.ts:
    - Import logger from electron/logger
    - Add IPC handler 'log:write' that receives LogEntry from renderer
    - Write renderer logs to separate file: renderer-%DATE%.log
    - Log application lifecycle events: app ready, window created, app quit
    - Log errors: window load errors, IPC handler errors
    - Wrap IPC handlers in try-catch, log errors with logger.error()

    Note: Per D-25, no crash reporting service (Sentry, etc.). Logs stay local.
  </action>
  <verify>
    <automated>npm run build && grep -q "winston" package.json && grep -q "logger" electron/logger.ts && test -f src/utils/logger.ts</automated>
  </verify>

  <action>
    Add comprehensive error handling for main process per D-23 (error handling), D-24 (logging).

    Create electron/crashHandler.ts:
    - Import app, dialog from electron
    - Import logger from electron/logger
    - Export function setupCrashHandlers(): void
      - Handle process.on('uncaughtException'):
        - Log error with logger.error('Uncaught exception', error)
        - Show dialog: "An unexpected error occurred. The application will restart."
        - app.relaunch()
        - app.exit(1)
      - Handle process.on('unhandledRejection'):
        - Log error with logger.error('Unhandled promise rejection', reason)
        - Continue running (don't crash on promise rejections)
      - Handle app.on('render-process-gone'):
        - Log event with details (reason, exitCode)
        - If reason is 'crashed': show dialog, offer to reload or quit
        - If reason is 'killed': log and continue
      - Handle app.on('child-process-gone'):
        - Log event with details
        - Continue running (child processes are non-critical)
    - Export function showErrorDialog(title: string, message: string): void
      - Use dialog.showErrorBox for synchronous error display
      - Use dialog.showMessageBox for async with buttons

    Update electron/main.ts:
    - Import setupCrashHandlers from crashHandler
    - Call setupCrashHandlers() before app.whenReady()
    - Wrap createWindow() in try-catch, log errors
    - Wrap all IPC handlers in try-catch:
      - On error: log with logger.error, return { success: false, error: error.message }
      - On success: return { success: true, data: result }
    - Add error handling for window load failures:
      - window.webContents.on('did-fail-load'): log error, show error page
    - Add error handling for server start failures (from Plan 03):
      - If startServer() throws: log error, fall back to desktop mode, show notification

    Add process monitoring:
    - Log memory usage every 5 minutes: process.memoryUsage()
    - Log CPU usage: process.cpuUsage()
    - Warn if memory usage exceeds 500MB (potential memory leak)

    Note: Per D-25, no external crash reporting. All errors logged locally.
