## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer → Main (IPC) | API keys cross from renderer (settings form) to main process for storage |
| Main → Disk | Encrypted API keys written to electron-store file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-23 | Information Disclosure | API keys visible in UI | mitigate | Masked input by default per D-25, reveal button for intentional viewing |
| T-03-24 | Information Disclosure | API keys in browser DevTools | accept | Electron renderer process, user has full control over their own machine |
| T-03-25 | Information Disclosure | API keys in error messages | mitigate | Sanitize validation errors, never include full API key in error text |
| T-03-26 | Tampering | Invalid provider config | mitigate | Validate API key before saving per D-05, validate model selection against hardcoded list |
| T-03-SC | Tampering | npm installs | mitigate | No new packages in this plan (uses existing React/Radix UI) |
</threat_model>
