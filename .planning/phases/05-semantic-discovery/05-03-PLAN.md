**Imports:**

**Function: setupVectorExtension(db: Database.Database): void**
- JSDoc: Load sqlite-vec extension for vector similarity search
- Determine platform-specific extension path:
  - Windows: `path.join(__dirname, '../extensions/vec0.dll')`
  - Linux: `path.join(__dirname, '../extensions/vec0.so')`
  - macOS: `path.join(__dirname, '../extensions/vec0.dylib')`
- Load extension: `db.loadExtension(extensionPath)`
- Verify extension loaded: `db.prepare('SELECT vec_version()').get()`
- Throw error if extension fails to load with helpful message

**Function: findSimilarNotes(db: Database.Database, noteId: string, queryVector: Float32Array, threshold: number, limit: number): Array<{ id: string; title: string; similarity: number }>**
- JSDoc: Find notes similar to query vector using cosine similarity per D-09 (threshold 0.7+)
- Convert Float32Array to Buffer: `Buffer.from(queryVector.buffer)`
- Execute SQL query using db.prepare().all():
  ```sql
  SELECT 
    n.id,
    n.title,
    vec_distance_cosine(e.vector, ?) as similarity
  FROM embeddings e
  INNER JOIN notes n ON e.note_id = n.id
  WHERE e.note_id != ?
    AND n.deleted_at IS NULL
    AND similarity >= ?
  ORDER BY similarity DESC
  LIMIT ?
  ```
- Bind parameters: vectorBlob, noteId, threshold, limit
- Return results array with id, title, similarity fields
- Return empty array if no results
