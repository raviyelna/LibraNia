## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → Express server | Untrusted browser requests cross here |
| File upload → filesystem | Untrusted file content crosses here |
| Encrypted API keys → decryption | Encrypted data at rest crosses to plaintext in memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Multer file uploads | mitigate | File type validation via magic bytes (fileFilter), size limit 10MB, sanitized filenames |
| T-01-02 | Information Disclosure | API key storage | mitigate | AES-256-GCM encryption with scrypt key derivation, auth tag prevents tampering |
| T-01-03 | Denial of Service | File upload size | mitigate | 10MB limit in Multer config, prevents memory exhaustion |
| T-01-04 | Tampering | Encrypted API keys | mitigate | GCM auth tag validation in decryptApiKey, throws on tampered ciphertext |
| T-01-SC | Tampering | npm installs | mitigate | slopcheck passed [OK] for socket.io, multer, dotenv — all approved packages |
</threat_model>
