<objective>
Create Socket.IO Context provider for single global WebSocket connection shared across all components. Enables real-time features (AI streaming, graph updates) without multiple connections.

Purpose: Replace Electron IPC event listeners (window.api.*.on*) with Socket.IO event handlers. Single connection prevents reconnection storms (Pitfall 2 in RESEARCH.md) and simplifies state management.

Output: SocketProvider wrapping App.tsx, useSocket hook available to all components. Connection status tracked and displayed via toast notifications.
</objective>
