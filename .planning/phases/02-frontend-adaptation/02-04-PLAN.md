<task type="auto">
  <name>Task 3: Configure backend to serve frontend static assets</name>
  <files>electron/server.ts</files>
  <action>
Read electron/server.ts. After all API routes are registered (after router.use calls), add static file serving middleware. Import path from 'path'. Add app.use(express.static(path.join(__dirname, '../dist'))) to serve built frontend files. This serves index.html, JS bundles, CSS, and assets from dist/ directory.

Add catch-all route for SPA routing: app.get('*', (req, res) => { res.sendFile(path.join(__dirname, '../dist/index.html')) }). This ensures React Router works - all non-API routes return index.html, letting React Router handle client-side routing. Place this AFTER static middleware but AFTER API routes (so API routes take precedence).

The order should be: 1) API routes (/api/*), 2) static file middleware (serves files from dist/), 3) catch-all route (returns index.html for SPA routing).
  </action>
  <verify>
    <automated>grep -q "express.static.*dist" electron/server.ts && grep -q "sendFile.*dist/index.html" electron/server.ts</automated>
  </verify>
  <done>Backend serves frontend static assets and handles SPA routing</done>
</task>
