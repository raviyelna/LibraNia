<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer machine → npm registry | prepublishOnly script ensures builds run before publish, prevents publishing stale code |
| npm registry → user's machine | postinstall script compiles native deps, requires build tools on user system |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Tampering | prepublishOnly script | mitigate | Automatically runs build:package before npm publish, prevents publishing unbuild or stale code |
| T-04-06 | Denial of Service | postinstall script | accept | Requires build tools on user machine, documented in README.md (standard npm pattern for native modules) |
| T-04-07 | Information Disclosure | npm pack tarball | mitigate | Verify tarball contents before publish, ensure no .env, .git, or test files included via files whitelist |
| T-04-08 | Tampering | Package size limit | mitigate | Verify tarball < 50MB before publish, prevents bloated packages with unnecessary files |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | Human verification checkpoint for package legitimacy before publish (commander, open, better-sqlite3, sharp) |
</threat_model>
