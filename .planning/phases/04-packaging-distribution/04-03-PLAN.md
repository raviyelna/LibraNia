<objective>
Test LibraNia package locally via npm pack and global install to verify packaging configuration before publishing.

Purpose: Validate the complete npm package works end-to-end on the local system. This includes creating the tarball, installing it globally, and verifying all CLI commands function correctly. Catches packaging issues (missing files, incorrect paths, broken dependencies) before publishing to npm registry.

Output: Verified package tarball < 50MB, successful global install, working CLI commands (--version, --help, start), confirmation all requirements PKG-01 through PKG-05 met.
</objective>

<tasks>

## Task 1: Create and verify package tarball

**What:** Run npm pack and verify tarball contents and size

**Why:** Validates files whitelist includes all necessary runtime files and excludes source/test files

**How:**
1. Run `npm run build:package` to compile all assets
2. Run `npm pack` to create tarball
3. Check tarball size < 50MB
4. Extract tarball to temp directory and verify contents:
   - bin/librania.js present
   - electron/*.js files present (compiled backend)
   - dist/index.html present (frontend)
   - node_modules/ NOT present (users install deps)
   - src/ NOT present (source excluded)
   - tests/ NOT present (tests excluded)

**Acceptance:**
- Tarball created successfully
- Size < 50MB
- Contains only whitelisted files from package.json

**Commit message:** `test(04-03): verify package tarball contents and size`

---

## Task 2: Test global installation and CLI commands

**What:** Install package globally from tarball and verify all CLI functionality

**Why:** Validates package installs correctly and all entry points work

**How:**
1. Install globally: `npm install -g ./librania-*.tgz`
2. Verify installation: `which librania` shows global bin path
3. Test version: `librania --version` shows correct version from package.json
4. Test help: `librania --help` displays usage instructions
5. Test start command: `librania start --no-browser` (headless mode)
   - Server starts on port 3000
   - No errors in console
   - Ctrl+C shuts down gracefully
6. Clean up: `npm uninstall -g librania`

**Acceptance:**
- Global install succeeds
- All CLI commands work correctly
- Server starts and stops cleanly
- All PKG requirements verified

**Commit message:** `test(04-03): verify global install and CLI functionality`

</tasks>

<technical_approach>

## Testing Strategy

**Local package testing workflow:**
1. Build → Pack → Install → Test → Uninstall
2. Validates complete user installation experience
3. Catches issues before npm publish

**Verification checklist:**
- ✓ Tarball size < 50MB (PKG-05)
- ✓ Global install works (PKG-01)
- ✓ Frontend assets bundled (PKG-02)
- ✓ --version works (PKG-03)
- ✓ --help works (PKG-04)
- ✓ Server starts successfully

**Native dependencies:**
- better-sqlite3 and sharp compile during install via postinstall hook
- Requires build tools on system (node-gyp, python, C++ compiler)
- Already documented in README.md from Plan 02

## Edge Cases

**If tarball > 50MB:**
- Check node_modules accidentally included
- Verify files whitelist in package.json
- Check dist/ size (frontend should be optimized by Vite)

**If global install fails:**
- Check bin/librania.js shebang present
- Verify package.json bin field correct
- Check file permissions (bin should be executable)

**If native deps fail to compile:**
- User needs build tools installed
- Error message should reference README.md requirements
- Not a blocker for this test (assumes dev machine has tools)

</technical_approach>
