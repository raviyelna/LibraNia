| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Information Disclosure | API keys in provider constructors | mitigate | Keys retrieved from secure.store only in main process, never logged |

| T-03-11 | Denial of Service | Infinite retry loops | mitigate | Max 3 retries with exponential backoff, skip retry on auth errors |
| T-03-12 | Denial of Service | Infinite streaming | mitigate | Timeout and max tokens limit enforced in IPC handlers (Plan 03-05) |
| T-03-SC | Tampering | npm installs | mitigate | No new packages in this plan (uses existing openai SDK from Plan 03-03) |
