## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer → Main (IPC) | API keys cross from renderer (settings UI) to main process for storage |
| Main → Disk | Encrypted API keys written to electron-store file |
| Main → OS Keychain | Encryption key stored in plain Store (future: migrate to safeStorage API) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Information Disclosure | API keys in plaintext on disk | mitigate | electron-store AES-256 encryption with encryptionKey option |
| T-03-06 | Information Disclosure | Encryption key in plaintext | accept | Encryption key stored in plain Store (low risk for single-user desktop app, future: migrate to safeStorage API per D-26) |
| T-03-07 | Information Disclosure | API keys in error messages | mitigate | Sanitize error messages in IPC handlers (Plan 03-06) |
| T-03-08 | Information Disclosure | API keys exposed to renderer | mitigate | Keys never sent to renderer, only stored/retrieved in main process (enforced in IPC handlers Plan 03-06) |
| T-03-SC | Tampering | npm installs (electron-store) | mitigate | Package verified in RESEARCH.md legitimacy audit: electron-store [OK], 1M+/wk downloads, 7+ years old |
</threat_model>
