Create electron/services/conversation.service.ts following notes.service.ts pattern from Phase 2:

**Type definitions:**
```typescript
export interface CreateConversationInput {
  title: string;  // Auto-generated from first 50 chars per D-11
}

export interface AddMessageInput {
  conversation_id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  provider_id?: string;  // 'claude', 'openai', 'deepseek' per D-06
  model?: string;        // Model name per D-23
}

export interface Citation {
  message_id: string;
  url: string;
  title: string;
  snippet: string;
  position: number;  // [1], [2], [3] per D-16
}

export interface Conversation {
  id: string;
  title: string;
  created_at: Date;
  updated_at: Date;
}

export interface Message {
  id: string;
  conversation_id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  provider_id: string | null;
  model: string | null;
  created_at: Date;
  citations?: Citation[];
}
```

**CRUD functions (follow notes.service.ts pattern):**

**createConversation(data: CreateConversationInput, db):**
- Generate UUID with crypto.randomUUID()
- Set created_at and updated_at to new Date()
- Insert into conversations table using db.insert(conversations).values().returning()
- Return Conversation object

**addMessage(data: AddMessageInput, db):**
- Generate UUID for message
- Set created_at to new Date()
- Insert into messages table with all fields
- Update conversation.updated_at to now
- Return Message object

**addCitations(citations: Citation[], db):**
- Generate UUID for each citation
- Set created_at to new Date()
- Batch insert into citations table using db.insert(citations).values(citations)
- Return inserted citations

**getConversation(id: string, db):**
- Query conversation by id
- Join messages and citations tables
- Group citations by message_id
- Return Conversation with messages array, each message with citations array

**getAllConversations(db):**
- Query all conversations ordered by updated_at DESC
- Return Conversation[] (without messages for list view performance)

**deleteConversation(id: string, db):**
- Delete conversation by id (CASCADE deletes messages and citations automatically)
- Return void

**updateConversationTitle(id: string, title: string, db):**
- Update conversation title and updated_at
- Return updated Conversation

Use Drizzle ORM with parameterized queries (eq, desc, and from drizzle-orm). Follow error handling pattern from notes.service.ts (throw errors for not found).
