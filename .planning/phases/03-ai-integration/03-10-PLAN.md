Create chat operations hook with streaming support:

**useChat.ts:**

Export three hooks:

1. **useSendMessage(conversationId?: string)** - Send message with streaming
   - State: loading, error, streamingContent (accumulated tokens)
   - Function: sendMessage(message: string, providerId: string) 
     - Call window.api.chat.send({ conversationId, message, providerId })
     - Register window.api.chat.onToken((token) => setStreamingContent(prev => prev + token))
     - Clean up with window.api.chat.offToken() in useEffect cleanup
     - Return full response when complete
   - Return: { sendMessage, loading, error, streamingContent }

2. **useSummarizeNote(noteId: string)** - Generate note summary
   - State: loading, error, summary
   - Function: summarize(providerId: string) calls window.api.chat.summarizeNote({ noteId, providerId })
   - Return: { summarize, loading, error, summary }

3. **useChat(conversationId?: string)** - Combined hook
   - Combines useSendMessage and useSummarizeNote
   - Return: { sendMessage, summarize, loading, error, streamingContent, summary }

Follow mutation hook pattern from useCreateNote (lines 63-77 in PATTERNS.md). Handle streaming cleanup in useEffect with return () => window.api.chat.offToken().
