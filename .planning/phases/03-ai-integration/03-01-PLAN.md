<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → process.env | User-provided port/path values cross into server configuration |
| File system → distPath | CLI resolves dist directory path for static file serving |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | CLI port argument | mitigate | Validate port is integer 1024-65535 in bin/librania.js before passing to startServer |
| T-03-02 | Denial of Service | CLI data-dir argument | mitigate | Validate path exists or can be created, reject absolute paths outside user home |
| T-03-03 | Information Disclosure | CLI help output | accept | Help text reveals no sensitive data, only usage instructions |
| T-03-SC | Tampering | npm install commander | mitigate | commander@^12.1.0 verified on npm registry, no slopcheck needed (established package) |
</threat_model>
