  <name>Task 1: Implement theme system with CSS custom properties and Context API</name>
  <files>
    src/contexts/ThemeContext.tsx

    src/index.css
    tailwind.config.js

  <behavior>
    - Theme context provides current theme ('light' | 'dark' | 'system')
    - toggleTheme() cycles through light → dark → system
    - setTheme(theme) sets specific theme
    - On mount, reads system preference via window.matchMedia('(prefers-color-scheme: dark)')
    - Theme changes apply CSS custom properties and Tailwind dark mode class
    - Theme preference persists to localStorage (preparation for D-16 config file in Plan 04)
  </behavior>
  <action>
    Create theme system implementing D-14 (hybrid CSS custom properties + Tailwind dark mode), D-15 (system preference default), D-16 (persistence).

    Create src/types/theme.ts:
    - Export type Theme = 'light' | 'dark' | 'system'
    - Export interface ThemeContextValue with theme, effectiveTheme, setTheme, toggleTheme

    Create src/contexts/ThemeContext.tsx:
    - Create ThemeContext with React.createContext per D-05 (Context + hooks)
    - ThemeProvider component manages theme state
    - On mount: read localStorage 'theme' key, fallback to 'system'
    - If theme is 'system', detect via window.matchMedia('(prefers-color-scheme: dark)')
    - Listen to system theme changes with matchMedia.addEventListener('change')
    - Apply theme by setting document.documentElement.classList ('dark' class for dark mode)
    - Save theme to localStorage on change
    - Provide { theme, effectiveTheme, setTheme, toggleTheme }

    Create src/hooks/useTheme.ts:
    - Export useTheme hook that calls useContext(ThemeContext)
    - Throw error if used outside ThemeProvider

    Update src/index.css:
    - Define CSS custom properties in :root for light theme colors
    - Define CSS custom properties in :root.dark for dark theme colors
    - Variables: --color-background, --color-foreground, --color-primary, --color-secondary, --color-border, --color-muted
    - Light theme: white backgrounds, dark text
    - Dark theme: dark backgrounds, light text

    Update tailwind.config.js:
    - Set darkMode: 'class' (uses .dark class on html element)
    - Extend theme.colors to use CSS custom properties: backgroundColor: { DEFAULT: 'var(--color-background)' }
    - Map Tailwind utilities to CSS variables for consistency
  </action>
  <verify>
    <automated>npm run build && grep -q "ThemeProvider" src/contexts/ThemeContext.tsx && grep -q "darkMode: 'class'" tailwind.config.js</automated>
  </verify>
  <done>Theme context provides theme state, CSS custom properties defined for both themes, Tailwind configured for dark mode</done>
</task>
