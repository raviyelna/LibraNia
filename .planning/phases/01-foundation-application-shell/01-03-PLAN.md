  <behavior>
    - loadConfig() reads config.json from app data directory, returns default if missing
    - saveConfig(config) writes config.json atomically (write temp file, rename)
    - Config includes: mode ('desktop' | 'web'), theme ('light' | 'dark' | 'system'), windowBounds ({ x, y, width, height })
    - Config file location: app.getPath('userData')/config.json
    - Invalid JSON falls back to defaults without crashing
  </behavior>
  <action>
    Create configuration management system implementing D-09 (JSON config file), D-16 (theme persistence), D-17 (window bounds persistence).

    Install dependencies:
    - None (use Node.js fs module)

    Create src/types/config.ts:
    - Export type AppMode = 'desktop' | 'web'
    - Export interface WindowBounds { x: number; y: number; width: number; height: number }
    - Export interface AppConfig { mode: AppMode; theme: 'light' | 'dark' | 'system'; windowBounds: WindowBounds | null; serverPort: number }
    - Export const DEFAULT_CONFIG: AppConfig with mode: 'desktop', theme: 'system', windowBounds: null, serverPort: 3000

    Create src/config/appConfig.ts:
    - Import fs/promises, path, app from electron
    - Export function getConfigPath(): string returns path.join(app.getPath('userData'), 'config.json')
    - Export async function loadConfig(): Promise<AppConfig>
      - Try to read config file with fs.readFile
      - Parse JSON, validate structure
      - Merge with DEFAULT_CONFIG (handle partial configs)
      - Return merged config
      - On error (file not found, invalid JSON), return DEFAULT_CONFIG
    - Export async function saveConfig(config: Partial<AppConfig>): Promise<void>
      - Load current config
      - Merge with new values
      - Write to temp file: config.json.tmp
      - Rename temp file to config.json (atomic operation)
      - Ensure userData directory exists with fs.mkdir({ recursive: true })
    - Export async function updateConfig(updates: Partial<AppConfig>): Promise<AppConfig>
      - Load current config
      - Merge updates
      - Save merged config
      - Return updated config

    Update electron/main.ts:
    - Import loadConfig, saveConfig from appConfig
    - On app.whenReady(), call loadConfig() to get initial mode
    - Store config in module-level variable
    - Expose IPC handlers: 'config:get', 'config:set', 'config:update'
    - IPC handler 'config:set' validates input with Zod schema before saving

    Note: better-sqlite3 (D-03) will be initialized in Phase 2 for note storage. Phase 1 uses JSON config for app settings only.
  </action>

<task type="auto" tdd="true">
  <name>Task 2: Create embedded HTTP server for web mode with dev/prod clarity</name>
  <files>
    electron/server.ts
    electron/main.ts
    package.json
  </files>
  <behavior>
    - startServer(port) creates HTTP server serving built React app
    - Server serves static files from dist/ directory (production only)
    - Server handles SPA routing (all routes return index.html)
    - Server starts only when mode is 'web'
    - Server port configurable via config (default 3000)
    - stopServer() cleanly shuts down server
    - Server logs requests to console
    - Development: Vite dev server runs separately on port 5173, Electron loads from it
    - Production: Express server serves built files from dist/
  </behavior>
  <action>
    Create embedded web server implementing D-02 (web mode via embedded server).

    Install dependencies:
    - express ^4.21.0 (lightweight HTTP server)
    - @types/express (dev dependency)

    Create electron/server.ts:
    - Import express, path, app from electron
    - Export interface ServerInstance { server: http.Server; port: number }
    - Export async function startServer(port: number = 3000, distPath: string): Promise<ServerInstance>
      - Create express app
      - Serve static files from distPath (path.join(__dirname, '../dist') in production)
      - Add middleware: express.static for assets
      - Add catch-all route: app.get('*', (req, res) => res.sendFile(index.html)) for SPA routing
      - Start server with server.listen(port)
      - Return { server, port }
      - Log: "Web server started on http://localhost:{port}"
    - Export function stopServer(instance: ServerInstance): Promise<void>
      - Call server.close() with promise wrapper
      - Log: "Web server stopped"
    - Handle errors: port already in use (try port + 1), file not found (log error)

    Update electron/main.ts with dev/prod mode clarity:
    - Import startServer, stopServer from server.ts
    - After loadConfig(), check if config.mode === 'web'
    - If web mode:
      - **Development (process.env.VITE_DEV_SERVER_URL exists):**
        - Do NOT start Express server
        - Load Vite dev server URL directly: loadURL(process.env.VITE_DEV_SERVER_URL)
        - Vite serves React app with HMR on port 5173
      - **Production (built files exist):**
        - Start Express server: startServer(config.serverPort, path.join(__dirname, '../dist'))
        - Load Express server URL: loadURL(`http://localhost:${port}`)
        - Express serves static files from dist/
    - If desktop mode:
      - **Development:** loadURL(process.env.VITE_DEV_SERVER_URL) — Electron window loads Vite dev server
      - **Production:** loadFile(path.join(__dirname, '../dist/index.html')) — Electron window loads built files directly
    - Store server instance in module variable
    - On app.quit(), call stopServer() if server is running
    - Add IPC handler 'mode:switch' that saves new mode to config and shows Radix Dialog: "Restart required to switch modes. Restart now?" with buttons [Cancel, Restart]
    - If user clicks Restart: app.relaunch() then app.quit()

    Security: Server only listens on localhost (127.0.0.1), not exposed to network.

    Clarification per verification feedback (Blocker 6):
    - **Desktop mode dev:** Electron BrowserWindow → Vite dev server (localhost:5173) → HMR works
    - **Desktop mode prod:** Electron BrowserWindow → file:// protocol → dist/index.html
    - **Web mode dev:** Electron BrowserWindow → Vite dev server (localhost:5173) → HMR works (no Express)
    - **Web mode prod:** Electron BrowserWindow → Express server (localhost:3000) → dist/ static files
  </action>
  <verify>
    <automated>npm run build && grep -q "startServer" electron/server.ts && grep -q "express" package.json</automated>
  </verify>
  <done>HTTP server starts in web mode (production only), serves React app, handles SPA routing, mode switching triggers restart prompt, dev/prod paths documented</done>
