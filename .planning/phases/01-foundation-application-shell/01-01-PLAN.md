<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer → Main Process | Untrusted renderer communicates with privileged main process via IPC |
| External Files → Application | User-provided documents/images loaded into application |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | electron/preload.ts | mitigate | Use contextBridge with explicit API surface, disable nodeIntegration, enable contextIsolation |
| T-01-02 | Information Disclosure | electron/main.ts | mitigate | Disable nodeIntegration in renderer, use preload script for controlled IPC only |
| T-01-03 | Elevation of Privilege | IPC handlers | mitigate | Validate all IPC messages in main process before execution, use allowlist pattern |
| T-01-SC | Tampering | npm installs | mitigate | Package legitimacy audit completed (see RESEARCH.md) — all packages approved |
</threat_model>
