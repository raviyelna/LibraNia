<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → CSS | User-controlled browser settings (prefers-reduced-motion, font size) affect rendering |
| CDN → Application | Google Fonts CDN delivers font files (external dependency) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | Google Fonts CDN | accept | Low risk: CDN failure causes fallback to system fonts (graceful degradation via font-family stack) |
| T-01-02 | Tampering | CSS custom properties | accept | Low risk: CSS runs in user's browser context, no server-side impact, CSP headers handle injection (Phase 2+) |
| T-01-03 | Information Disclosure | Design tokens | accept | No risk: Design tokens are public by nature (colors, spacing, fonts), no sensitive data |
</threat_model>
