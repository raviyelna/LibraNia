  </what-built>
  <how-to-verify>
Verify each package on npm registry:

1. **sharp** - https://www.npmjs.com/package/sharp
   - Publisher: lovell
   - Weekly downloads: ~10M
   - Repository: github.com/lovell/sharp
   - Age: 12+ years
   - Expected: Legitimate image processing library

2. **pdf-parse** - https://www.npmjs.com/package/pdf-parse
   - Publisher: mehmet-kozan
   - Weekly downloads: ~500K
   - Repository: github.com/mehmet-kozan/pdf-parse
   - Age: 7+ years
   - Expected: Legitimate PDF text extraction library

3. **mammoth** - https://www.npmjs.com/package/mammoth
   - Publisher: mwilliamson
   - Weekly downloads: ~10M
   - Repository: github.com/mwilliamson/mammoth.js
   - Age: 13+ years
   - Expected: Legitimate DOCX parser

4. **file-type** - https://www.npmjs.com/package/file-type
   - Publisher: sindresorhus
   - Weekly downloads: ~50M
   - Repository: github.com/sindresorhus/file-type
   - Age: 12+ years
   - Expected: Legitimate MIME type detection library

Check for red flags:
- Typosquatting (similar names to popular packages)
- Recently created packages with high download claims
- Missing or suspicious repository links
- Publishers with no other packages
