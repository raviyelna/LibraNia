CRUD operations:
- createNote: Generate UUID with crypto.randomUUID(), set created_at and updated_at to Date.now(), insert into notes table, return created note
- updateNote: Update title/body/metadata, set updated_at to Date.now(), WHERE id = ? AND deleted_at IS NULL

- getAllNotes: SELECT * FROM notes WHERE deleted_at IS NULL ORDER BY updated_at DESC
- getDeletedNotes: SELECT * FROM notes WHERE deleted_at IS NOT NULL ORDER BY deleted_at DESC

Use Drizzle's type-safe query builder: db.select().from(notes).where(eq(notes.id, id)).

    - updateNoteLinks deletes existing links for source note, parses body, finds target notes by title (case-insensitive), inserts new link records
    - getBacklinks returns all notes linking to target note, ordered by link count DESC then title ASC

  <action>
Create wiki-link parser per D-04 (user locked [[wiki-style]] syntax with case-insensitive matching). Use regex pattern from RESEARCH.md Pattern 3: /\[\[([^\]|]+)(?:\|([^\]]+))?\]\]/g

WikiLink interface:
```typescript
interface WikiLink {
  raw: string;        // "[[Note Title|Alias]]"
  title: string;      // "Note Title"
  alias?: string;     // "Alias" (optional)
  startIndex: number;
  endIndex: number;
}
```

parseWikiLinks implementation:
- Use regex.exec() in while loop to find all matches
- Extract title from match[1], alias from match[2] (if present)
- Return array of WikiLink objects

updateNoteLinks implementation:
- Delete existing links: db.delete(links).where(eq(links.sourceNoteId, noteId))
- Parse wiki-links from body text
- For each link, find target note by title (case-insensitive): db.select().from(notes).where(sql`lower(${notes.title}) = lower(${link.title})`).limit(1)
- If target found, insert link record: db.insert(links).values({ id: crypto.randomUUID(), sourceNoteId, targetNoteId, createdAt: Date.now() })
- If target not found, skip (broken link, will show dimmed in UI per D-04)

getBacklinks implementation per RESEARCH.md Pattern 4:
- Join links and notes tables
- WHERE links.targetNoteId = ? AND notes.deleted_at IS NULL
- GROUP BY notes.id, COUNT links
- ORDER BY link count DESC, title ASC

Write tests first (TDD): verify parseWikiLinks extracts titles and aliases, verify updateNoteLinks creates link records, verify case-insensitive matching, verify getBacklinks returns source notes, verify backlinks exclude deleted notes.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer → Main (IPC) | Renderer sends note data via IPC, main process validates and persists |
| Main → SQLite | Drizzle ORM uses parameterized queries to prevent SQL injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | IPC note data | mitigate | Validate title/body length limits (title max 500 chars, body max 1MB), reject null bytes |
| T-02-06 | Denial of Service | Large note body | mitigate | Enforce 1MB body size limit in IPC handler, reject larger payloads |
| T-02-07 | Tampering | SQL injection via wiki-link titles | mitigate | Use Drizzle parameterized queries, never concatenate user input into SQL |
| T-02-08 | Information Disclosure | Deleted notes in backlinks | mitigate | Filter deleted_at IS NULL in getBacklinks query |
| T-02-SC | Tampering | npm installs | mitigate | All packages passed slopcheck (RESEARCH.md) |
</threat_model>
