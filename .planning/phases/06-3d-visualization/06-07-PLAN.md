  <action>
Add two useEffect hooks to GraphView component:

**1. Window resize handler:**
- Listen for window resize events
- When window resizes, call fgRef.current.width() and fgRef.current.height() with new dimensions
- Use window.innerWidth and window.innerHeight for dimensions
- Clean up event listener on unmount

**2. Tab visibility handler:**
- Listen for document visibilitychange event
- When document becomes visible (user switches back to tab), reload graph data
- Call refetch() from useGraph hook (add refetch to hook's return if not present)
- Alternative: listen for window focus event if visibilitychange not sufficient
- Clean up event listener on unmount

Implementation notes:
- Place both useEffect hooks after existing useEffect hooks (after line 114)
- Check fgRef.current exists before calling methods
- Debounce resize handler if needed (optional, test first)
- For tab visibility, only reload if document.hidden === false (tab is now visible)

If useGraph hook doesn't expose refetch, modify hook to return refetch function from underlying query/state management.
