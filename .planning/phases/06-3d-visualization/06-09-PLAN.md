Investigate why search highlighting isn't working despite existing code (lines 168-179):

**Current implementation analysis:**
- searchMatchIds state exists (line 24)
- handleSearchResults updates searchMatchIds (lines 88-90)
- nodeColor function has priority logic (lines 168-179):
  - Priority 1: Search matches → '#fbbf24'
  - Priority 2: Neighbor highlighting
  - Priority 3: Tag-based colors

**Likely root causes:**
1. nodeThreeObject (lines 155-165) creates InstancedMesh with fixed color, overriding nodeColor
2. nodeColor prop may not apply to instanced meshes
3. Color update not triggering re-render

**Fix approach:**

Option A (Recommended): Update nodeThreeObject to respect search highlighting
- In nodeThreeObject function (lines 155-165), check searchMatchIds before setting color
- Apply yellow/gold color (#fbbf24) if node.id is in searchMatchIds
- This ensures instanced mesh color matches search state

Option B: Force re-render when searchMatchIds changes
- Add useEffect that triggers ForceGraph3D refresh when searchMatchIds changes
- Call fgRef.current.refresh() or similar method

Option C: Disable instanced rendering for highlighted nodes
- When searchMatchIds.size > 0, return null from nodeThreeObject for matching nodes
- Let nodeColor prop handle highlighting (fallback to default rendering)

**Implementation (Option A - most performant):**

Modify nodeThreeObject function (lines 155-165):
```typescript
nodeThreeObject={(node: any) => {
  const mesh = new THREE.InstancedMesh(geometry, material, 1);
  
  // Determine color based on search/highlight state
  let color: string;
  if (searchMatchIds.size > 0 && searchMatchIds.has(node.id)) {
    color = '#fbbf24'; // Search match - yellow/gold
  } else if (highlightNodes.size > 0) {
    color = highlightNodes.has(node.id) ? '#ffffff' : '#444444';
  } else {
    color = getColorForTag(node.tags?.[0]);
  }
  
  mesh.setColorAt(0, new THREE.Color(color));
  mesh.instanceColor!.needsUpdate = true;
  return mesh;
}}
```

Add useEffect to trigger re-render when searchMatchIds changes:
```typescript
useEffect(() => {
  if (fgRef.current) {
    fgRef.current.refresh();
  }
}, [searchMatchIds]);
```
