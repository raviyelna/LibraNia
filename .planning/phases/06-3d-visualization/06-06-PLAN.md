  <name>Task 1: Add extension-based fallback to validateFileType</name>
  <files>electron/services/content.service.ts</files>
  <action>
Modify validateFileType function (lines 81-94) to add extension-based fallback when fileTypeFromBuffer returns undefined:

1. Accept filePath parameter (string) in addition to buffer
2. When fileTypeFromBuffer returns undefined, extract extension from filePath using path.extname
3. Map extension to MIME type:
   - .txt → text/plain
   - .md → text/markdown
4. Verify mapped MIME type is in ALLOWED_MIME_TYPES
5. Return { mime, ext } for text files
6. Only throw "Unable to determine file type" if both magic bytes AND extension mapping fail

Implementation notes:
- Import path module at top of file if not already imported
- Extension check should be case-insensitive (.TXT and .txt both work)
- Preserve existing magic bytes validation as primary method
- Extension fallback is secondary (only when fileTypeFromBuffer returns undefined)

Update function signature from:
```typescript
export async function validateFileType(buffer: Buffer): Promise<{ mime: string; ext: string }>
```

To:
```typescript
export async function validateFileType(buffer: Buffer, filePath: string): Promise<{ mime: string; ext: string }>
```

Update createContent function (line 211) to pass filePath to validateFileType:
```typescript
const { mime, ext } = await validateFileType(fileBuffer, data.filePath);
```
